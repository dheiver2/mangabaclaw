Deploy MangabaClaw on Northflank with a one-click template and access it through the web Control UI. This is the easiest "no terminal on the server" path: Northflank runs the gateway for you.

## How to get started

1. Click [Deploy MangabaClaw](https://northflank.com/stacks/deploy-mangabaclaw) to open the template.
2. Create an [account on Northflank](https://app.northflank.com/signup) if you don't already have one.
3. Click **Deploy MangabaClaw now**.
4. Set these required environment variables:
   - `MANGABACLAW_GATEWAY_TOKEN` (use a strong random value)
   - `MANGABACLAW_STATE_DIR=/data/.mangabaclaw`
   - `MANGABACLAW_WORKSPACE_DIR=/data/workspace`
5. Click **Deploy stack** to build and run the MangabaClaw template.
6. Wait for the deployment to complete, then click **View resources**.
7. Open the MangabaClaw service.
8. Open the public MangabaClaw URL at `/mangabaclaw` and connect using the configured shared secret. This template uses `MANGABACLAW_GATEWAY_TOKEN` by default; if you replace it with password auth, use that password instead.

From the Northflank shell, run the read-only deployment preflight:

```bash
mangabaclaw doctor --json
```

## What you get

- Hosted MangabaClaw Gateway + Control UI
- Persistent storage via a Northflank Volume (`/data`) so `mangabaclaw.json`, per-agent `auth-profiles.json`, channel/provider state, sessions, and workspace survive redeploys

## Connect a channel

Use the Control UI at `/mangabaclaw`, or run `mangabaclaw onboard` via SSH for channel setup instructions:
