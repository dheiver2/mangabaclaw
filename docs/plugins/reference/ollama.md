# Ollama plugin

Adds Ollama, Ollama Cloud model provider support to MangabaClaw.

## Distribution

- Package: `@mangabaclaw/ollama-provider`
- Install route: included in MangabaClaw

## Surface

providers: `ollama`, `ollama-cloud`; contracts: `embeddingProviders`, `tools`, `webSearchProviders`
