# MangabaClaw BytePlus Provider

Official MangabaClaw provider plugin for BytePlus model inference and Seedance
video generation.

Install from MangabaClaw:

```bash
mangabaclaw plugins install @mangabaclaw/byteplus-provider
mangabaclaw gateway restart
```

Set `BYTEPLUS_API_KEY`, then select a `byteplus/*` or `byteplus-plan/*` model.

See <https://docs.mangabaclaw.ai/concepts/model-providers#byteplus-international>
for model setup and <https://docs.mangabaclaw.ai/tools/video-generation> for
Seedance video generation.
