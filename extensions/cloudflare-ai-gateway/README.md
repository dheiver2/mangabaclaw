# MangabaClaw Cloudflare AI Gateway Provider

Official MangabaClaw provider plugin for Cloudflare AI Gateway.

Install from MangabaClaw:

```bash
mangabaclaw plugins install @mangabaclaw/cloudflare-ai-gateway-provider
mangabaclaw gateway restart
```

See <https://docs.openclaw.ai/providers/cloudflare-ai-gateway> for setup and configuration.
