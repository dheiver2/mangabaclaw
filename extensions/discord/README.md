# MangabaClaw Discord

Official MangabaClaw channel plugin for Discord servers, channels, DMs, slash commands, and app events.

Install from MangabaClaw:

```bash
mangabaclaw plugins install @mangabaclaw/discord
```

Configure a Discord bot token and the channels or servers MangabaClaw should handle. The plugin lets MangabaClaw agents receive Discord messages and respond through the configured Discord app.
