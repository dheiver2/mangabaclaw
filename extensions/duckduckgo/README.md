# MangabaClaw DuckDuckGo Plugin

Official MangabaClaw plugin for DuckDuckGo web search.

Install from MangabaClaw:

```bash
mangabaclaw plugins install @mangabaclaw/duckduckgo-plugin
mangabaclaw gateway restart
```

See <https://docs.openclaw.ai/tools/duckduckgo-search> for setup and configuration.
