# MangabaClaw Feishu/Lark

Official MangabaClaw channel plugin for Feishu and Lark workplace chats. Community maintained by @m1heng.

Install from MangabaClaw:

```bash
mangabaclaw plugins install @mangabaclaw/feishu
```

Configure the Feishu/Lark app credentials in MangabaClaw, then connect the plugin to the chats where agents should receive and send messages.
