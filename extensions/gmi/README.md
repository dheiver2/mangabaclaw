# MangabaClaw GMI Cloud Provider

Official MangabaClaw provider plugin for hosted GMI Cloud models through an
OpenAI-compatible API.

Install from MangabaClaw:

```bash
mangabaclaw plugins install @mangabaclaw/gmi-provider
mangabaclaw gateway restart
```

Configure a GMI Cloud API key, then select models with refs such as
`gmi/openai/gpt-5.6-sol`.
