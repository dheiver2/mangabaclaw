# MangabaClaw LongCat Provider

Official MangabaClaw provider plugin for LongCat-2.0 through LongCat's hosted
OpenAI-compatible API.

Install from MangabaClaw:

```bash
mangabaclaw plugins install @mangabaclaw/longcat-provider
mangabaclaw gateway restart
```

Configure `LONGCAT_API_KEY`, then select `longcat/LongCat-2.0`.
