# MangabaClaw NovitaAI provider

Official MangabaClaw provider plugin for NovitaAI's OpenAI-compatible API.

## Install

```sh
mangabaclaw plugins install @mangabaclaw/novita-provider
mangabaclaw gateway restart
```

## Docs

See `docs/providers/novita.md` in the MangabaClaw repository, or the published
docs at `https://docs.mangabaclaw.ai/providers/novita`.
