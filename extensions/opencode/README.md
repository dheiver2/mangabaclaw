# OpenCode Zen MangabaClaw provider

Official MangabaClaw provider plugin for the OpenCode Zen model catalog, image
understanding, and native OpenCode session browsing.

## Install

```sh
mangabaclaw plugins install @mangabaclaw/opencode-provider
mangabaclaw gateway restart
```

## Docs

See `docs/providers/opencode.md` in the MangabaClaw repository, or the published
docs at `https://docs.mangabaclaw.ai/providers/opencode`.
