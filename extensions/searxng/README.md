# SearXNG MangabaClaw plugin

Official MangabaClaw plugin for SearXNG.

## Install

```sh
mangabaclaw plugins install @mangabaclaw/searxng-plugin
```

## Docs

See `docs/tools/searxng-search.md` in the MangabaClaw repository, or the published docs at `https://docs.mangabaclaw.ai/tools/searxng-search`.
