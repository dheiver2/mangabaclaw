# MangabaClaw Synthetic Provider

Official MangabaClaw provider plugin for Synthetic's hosted Anthropic-compatible
API.

Install from MangabaClaw:

```bash
mangabaclaw plugins install @mangabaclaw/synthetic-provider
mangabaclaw gateway restart
```

Configure `SYNTHETIC_API_KEY`, then select a `synthetic/<model-id>` model.

See https://docs.openclaw.ai/providers/synthetic for model and configuration
details.
