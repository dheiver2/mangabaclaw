# Tencent Cloud MangabaClaw provider

Official MangabaClaw provider plugin for Tencent Cloud.

## Install

```sh
mangabaclaw plugins install @mangabaclaw/tencent-provider
```

## Docs

See `docs/providers/tencent.md` in the MangabaClaw repository, or the published docs at `https://docs.openclaw.ai/providers/tencent`.
