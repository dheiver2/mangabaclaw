# Vercel AI Gateway MangabaClaw provider

Official MangabaClaw provider plugin for Vercel AI Gateway.

## Install

```sh
mangabaclaw plugins install @mangabaclaw/vercel-ai-gateway-provider
```

## Docs

See `docs/providers/vercel-ai-gateway.md` in the MangabaClaw repository, or the published docs at `https://docs.openclaw.ai/providers/vercel-ai-gateway`.
