# MangabaClaw Volcengine Provider

Official MangabaClaw provider plugin for Volcengine models, the Volcengine coding
plan, and Volcengine Speech text-to-speech.

Install from MangabaClaw:

```bash
mangabaclaw plugins install @mangabaclaw/volcengine-provider
mangabaclaw gateway restart
```

See <https://docs.openclaw.ai/providers/volcengine> for model and speech setup.
