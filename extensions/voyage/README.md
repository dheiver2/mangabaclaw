# MangabaClaw Voyage Provider

Official MangabaClaw memory embedding provider plugin for Voyage AI.

Install from MangabaClaw:

```bash
mangabaclaw plugins install @mangabaclaw/voyage-provider
mangabaclaw gateway restart
```

Set `VOYAGE_API_KEY`, then configure memory search with `provider: "voyage"`.
See <https://docs.openclaw.ai/reference/memory-config> for setup and
configuration.
