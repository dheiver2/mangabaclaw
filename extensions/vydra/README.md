# MangabaClaw Vydra Provider

Official MangabaClaw provider plugin for Vydra image, video, and speech generation.

Install from MangabaClaw:

```bash
mangabaclaw plugins install @mangabaclaw/vydra-provider
mangabaclaw gateway restart
```

Set `VYDRA_API_KEY`, then configure an image, video, or speech model. See
<https://docs.openclaw.ai/providers/vydra> for capability details and examples.
